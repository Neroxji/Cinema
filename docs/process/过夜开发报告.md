**子代理对 spec 沉默处的解读**（全部已落实现与测试，详见智能体使用记录各卡）：
- 下架影片不级联取消场次；取消场次在"已售**或锁定**"座位时均拒绝（spec 只写已售，保守处理）。
- 时段冲突 = 同影厅 PUBLISHED 场次区间重叠（放映时长=影片 duration_min，缓冲 0）。
- 影厅创建由工厂固定模板决定（IMAX 5 排×10 列=50 座含黄金区、普通 6×8=48 座）。
- 改签差价不结算（新票按新场次策略重计价）；选座优先同排同号。
- 候补准入：仅未开映满座场次；递补不锚定具体座位（claim 时取当前空闲位）。
- order_no 22 位、pickup_code 8 位随机数字（全库唯一索引兜底 + 冲突重试）。
- 事件发布器 = Spring 事件同步同事务广播（回滚即通知回滚，I6 依赖此语义）。
- GET /api/notifications 仅列表只读，read_flag 恒 false（守 spec 20 接口清单）。
